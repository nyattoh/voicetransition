# 声変わりシミュレータ

短い録音の高さと響きを調整し、原音と変換結果を聴き比べるためのブラウザ実験です。音声の解析と変換は端末内で行い、音声の外部送信やモデルの学習は行いません。本人の別の年齢や性別の声を復元するものではありません。

## 起動と入力

`index.html` をブラウザで開きます。録音には、ブラウザのマイク権限と HTTPS または localhost の環境が必要です。例えば Python がインストールされている場合、このフォルダーで次を実行し、`http://localhost:8000/` を開きます。

```powershell
py -m http.server 8000 --bind 127.0.0.1
```

「マイクを有効化」して録音するか、ブラウザが読み込める音声ファイルを選択します。録音は最大10秒です。長いファイルは先頭10秒を使用し、複数チャンネルの入力はモノラルにします。原音の再生・WAV保存も、この処理対象の音声です。

## 変換と比較

1. 入力を解析した後、入力の音響プロファイルを確認し、必要なら手動で選択します。
2. 変換先を選び、「ピッチ微調整」と「最終フォルマント比」で高さと響きを調整します。入力・変換先のプロファイルは便宜的な設定名であり、本人の年齢や性自認を確定するものではありません。
3. 「変換する」を押すと、同じ処理対象の原音から旧方式と新方式を生成します。原音、旧方式、新方式を再生し、それぞれ WAV として保存できます。再度変換するときも入力から処理します。

新方式は無声と判定した部分を原音に近づけます。判定や処理による音質の変化があり得るため、息や子音を含めて聴き比べてください。入力が変換済みの音声であれば、それを元の未変換録音に戻す機能ではありません。

## 評価と限界

画面の評価欄には F0 とフォルマントの推定値などを表示します。これらは粗い音響指標であり、自然さや特定の年齢・性別らしさを保証しません。本人らしさや自然さは、人が同じ音量で原音・旧方式・新方式を比較して判断する必要があります。

「DSP自動テストを実行」からページ内の自己テストを実行できます。テストの通過は、実際の録音、各ブラウザの動作、聴感上の品質を保証しません。対応状況と実機確認は使用する端末・ブラウザで確認してください。
